# mikelneonedwin/skills

A consolidated repository for my personal assistant skills.

## Included Skills

- **[gh-report](./skills/productivity/gh-report/SKILL.md)**: GitHub daily report skills — turns commits and PRs into casual daily check-ins.

## Installation

To install all skills in this repository, run:

```bash
npx skills install https://github.com/mikelneonedwin/skills
```
